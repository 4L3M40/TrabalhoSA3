# 💸 Troco | Trabalho SENAI SA3

Um projeto em **Java** para calcular o troco de uma compra e determinar o menor número de notas e moedas necessárias para compor o valor.

---

## 📝 Descrição

Este programa solicita o valor total da compra e o valor recebido pelo cliente, calcula o troco e exibe a quantidade mínima de notas e moedas necessárias para devolvê-lo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE recomendada:** IntelliJ IDEA ou Eclipse
- **Versão do JDK:** 11 ou superior

---

## ✨ Funcionalidades

- Solicitar o valor total da compra e o valor recebido.
- Validar se o valor recebido é suficiente para pagar a compra.
- Calcular o troco.
- Determinar a quantidade mínima de notas (R$ 200, 100, 50, 20, 10, 5, 2) e moedas (R$ 1,00, 0,50, 0,25, 0,10, 0,05, 0,01) necessárias para compor o troco.
